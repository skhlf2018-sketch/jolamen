# 졸라맨 식당

졸라맨이 길에서 주운 돈 백만 원으로 식당을 차리고 운영하는 브라우저 게임입니다.
설치 없이 `index.html` 파일 하나만 브라우저로 열면 바로 플레이할 수 있어요.

## 플레이 방법

1. 타이틀 화면에서 **새 게임**을 누르고, 오프닝(6장면)을 보거나 건너뛴 뒤 **가게 문 열기**를 누릅니다.
2. 매일 **음식 가격**과 **광고비**를 정하고 **영업 시작**을 누릅니다.
3. 손님이 들어와 밥을 먹는 모습을 보고, 결과 화면(S~D 등급)으로 하루 결과를 확인합니다.
4. **다음 날**로 넘어가 계속 운영합니다. 자금이 0원이 되면 파산입니다.

진행 상황은 브라우저에 자동 저장되고, 다시 열면 **이어하기**로 계속할 수 있어요.

## 게임 규칙

| 항목 | 규칙 |
| --- | --- |
| 시작 자금 | ₩3,000,000 |
| 메뉴 가격 | 적정가의 112%까지는 평점이 조금 오르고, 62% 이하로 싸게 팔면 손님과 평점이 크게 늘지만 재료비 비율이 높아요. 그보다 비싸면 손님과 평점이 줄어요. |
| 광고비 | ₩100,000마다 손님 약 18명 증가. 광고비는 그대로 비용이에요. |
| 평점 | 별이 1개 줄 때마다 손님이 1~2명 줄어요 (날마다 1명 또는 2명). |
| 고정비 | 하루 ₩30,000 × 가격대 배수 |
| 민원 | 하루 55% 확률로 발생. 처음 비용은 구닥다리 ₩30,000 (성공 30%) / 일반 ₩50,000 (50%) / 최고급 ₩80,000~₩100,000 (100%). 가게가 커지면 하루 수입과 같은 비율로 비용도 커져요. |
| 해결 보너스 | 민원을 해결하면 그날 매출이 **1%~10%** 랜덤으로 올라요. 영업 전에 해결하면 다음 영업에 적용돼요. |
| 미해결 민원 | 무시하거나 해결에 실패하면 1개마다 **손님 ÷1.5, 매출 -10%** (계속 겹쳐요). 영업 전에 **해결하기**로 다시 처리할 수 있어요. |

## 가게 확장

돈을 모아 24단계까지 가게를 키울 수 있어요. 단계마다 손님이 늘고, **더 비싸고 고급스러운 메뉴**로 바뀌어요.
메뉴는 날마다 돌아가며 나오고, 메뉴마다 **적정가**가 있어요. 가격 슬라이더는 적정가 대비 비율로 움직이고, **적정가로** 버튼으로 바로 맞출 수 있어요.
처음 메뉴(김치찌개, 불고기, 돈까스, 제육볶음, 비빔밥, 떡볶이, 라면, 치킨, 카레, 오므라이스)의 적정가는 ₩4,000~₩18,000이에요.

## VIP 손님

매일 **5% 확률**로 아래 세 명 중 한 명이 찾아옵니다.

| VIP | 효과 |
| --- | --- |
| 부자 | 음식값의 **3배**를 혼자 결제하고 평점을 **1점** 올려 줘요. (최대 5.0) |
| 인플루언서 | SNS에 가게를 올려서 **다음 날 손님이 50%** 늘어나요. |
| 산타 | 돈 선물을 두고 가요. 처음엔 **₩50,000 ~ ₩100,000**이고, 가게가 커지면 하루 수입과 같은 비율로 커져요. |

만난 VIP는 화면 아래 **VIP 손님 도감**에 기록됩니다.

## 그 밖의 기능

- 타이틀 화면, 배경 음악과 효과음 (설정에서 각각 끌 수 있어요)
- 시간이 흐르는 2.5D 가게: 창밖이 아침에서 밤으로 바뀌고, 조명이 켜져요
- 손님이 낸 돈이 동전이 되어 자금 표시로 날아가요
- 업적 16개, 하루 결과 등급(S/A/B/C/D, 매출 대비 이익률 기준)

> 테스트 팁: 주소 끝에 `#vip`를 붙여 열면 (예: `index.html#vip`) VIP가 매일 찾아옵니다.
